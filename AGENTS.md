# Project maintenance

- Do not compute or compare hashes, explicit CRC values, or content digests for source, scripts, binaries, archives, or game executables.
- Identify a running game by process name, liveness and PID. Never use executable digests.
- Validate changes with compilation, meaningful behavior tests, artifact inventories and build identifiers.
- Keep one production automatic-parry scheduler. Historical solver functions are explicitly offline comparison entry points.
- Treat static permission timing as a candidate model; do not claim it is CCD-verified contact or an established success rate.
- Preserve Shift parry / Shift roll pause / F7 roll toggle, unless the requested change explicitly alters those controls.
- Preserve shared queue ownership, cancellation cleanup, and separation between animation observation and causal confirmation.
- Keep private logs, credentials, local paths and raw game assets outside this repository.
