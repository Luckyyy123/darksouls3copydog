# AI 使用说明

本维护分支新增及大幅重写的代码，绝大多数由生成式 AI 编写、修改和迭代完成；
文档也大量使用 AI 生成和整理。不把它描述为维护者亲自手写的工程。
这是开发方式的定性披露，没有逐行统计生成代码占比；继承的旧 Copydog 上游代码不归为本次 AI 创作。

- Codex：代码实现与整合、构建、调试、测试和发布整理。
- Claude Opus 5.5：通过实际 API 委派生成 SC23 纠正实现，并进行工程/仲裁与文档审查。
- DeepSeek Flash：实际接口参与分类、公式与代码复核；另有独立 GPT 测试和反例检查。
- 维护者与测试人员：需求、实测反馈、使用取舍和最低可用程度的验收。

维护者的验收不代表全部源码已经过人工逐行审查。

一些模型建议因端点公式、变量上下文或控制流误读被拒绝。多模型意见一致不构成验证。
文档列出的测试依赖实际编译/运行结果，不能据此声称量化实机成功率。

这里记录参与方式，不替上游或第三方决定许可，也不把使用 AI 本身当作代码质量保证。
