# 已知问题与验证边界

- SC23 是维护者最低可用基线；维护者仍不满意，不是最终版。
- 当前自动弹反采用静态许可时间候选，不要求距离/CCD 伤害接触证明；远处真实挥击可能空弹。
- 三个时间概念必须分开：敌方可被弹反许可、自身有效段、实际物理接触时间。前两者不能自动证明第三者。
- 长许可段可能只针对其 onset 作候选，不能保证后续全段覆盖。
- 敌方取消在本地提交之后发生时，不能撤回已经送入游戏的请求。
- native/visible/name 可能延迟或回读。已加入代际和旧槽保护，未证明不存在其它网络/混合动画边界。
- 显示的网络延迟没有自动等同于输入延迟或某一方向的单程延迟。
- 翻滚的落点、地面估算、延迟爆炸和多段范围攻击有模型和数据覆盖边界。
- 配置与地址只验证当前布局；不同版本、角色装备、Mod 组合与加载器共存需重新验证。
- 自动背刺/处决依赖原生状态和几何条件，发出请求不等于配对执行成功。
- 监测不能可靠识别每次物理按键来源；手动与自动事件可能重叠。
- 默认回归使用自有假内存、匿名片段和合成 oracle；没有量化的实机成功率、CPU 预算或多目标性能保证。
- 源码包含保留的历史功能与网络钩子，PvE 适配尚未完成。
- 原上游链接/许可及资源派生表的再分发依据尚未完整核实，见 LICENSING/PROVENANCE。
