# Copydog SC23 — experimental maintenance baseline

基线构建：`SC23-20261116-193139`。

这是基于旧版 Copydog 的实验维护分支，包含单一自动弹反入口、原生起手观察、
取消/代际处理、共享动作队列，以及恢复的自动翻滚和背刺功能。
源码包附带构建脚本、回归用例和只读监测工具；二进制包包含 DLL、加载器、配置与 notices。

**维护者仍不满意，目前仅达到个人最低可用要求。** 欢迎继续维护、重构和制作 PvE 专用分支。
它尚不是完整 PvE 成品。修改清单、已知问题、AI 参与和来源记录均在源码 README 与 docs 中。

- Shift：自动弹反，同时暂停自动翻滚。
- F7：切换自动翻滚；新游戏进程默认关闭。
- 当前弹反仍旁路距离/CCD 接触证明，许可时间候选不等于真实接触 TTI。
- 离线回归通过不代表已测得实机成功率、CPU 开销或全武器支持。
- 上游仓库与许可证尚未确认；维护者只允许其有权授权的新增实现继续维护和修改，
  不能据此给全部继承代码和游戏资源派生数据重新许可。

本次发布整理没有改变 SC23 游戏行为，也没有启动游戏或自动加载 DLL。
主二进制为 Windows x64 发布构建；不附带可选 ETW helper 的 NuGet 二进制。
